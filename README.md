# 有期

“有期”是一款面向未来时间安排的 Android 规划应用。名字取意于“未来有期、事事有期”：先决定什么时候做什么，再选择提前提醒时间，应用会在安排开始前准时发送通知。

进入应用后首先看到的是一整周时间网格。轻点任意日期与时间格即可创建安排，轻点已有色块即可编辑。桌面小组件会显示距离最近的一项安排，点击后进入该计划所在的周。

## 第一版功能

- 进入应用直接查看七日时间网格，支持切换上一周、下一周和回到本周。
- 点击任意日期与时间段创建计划，点击已有计划块进行编辑。
- 支持同一天重叠计划的并排展示。
- 当前日期、当前时间和已完成计划都有独立视觉状态。
- 新计划必须选择提前提醒时间：
  - 15 分钟
  - 30 分钟
  - 1 小时
  - 1.5 小时
  - 2 小时
- 当距离计划开始不足所选时间时，保存前会阻止无效提醒配置。
- 通知包含计划名称、时间段、分类与备注，并支持直接标记完成。
- 支持编辑、删除和完成计划。
- 桌面小组件展示距离最近的一项安排、准确时间、分类、所在日期以及当天计划数量。
- 点击桌面小组件打开对应计划所在的周。
- 手机重启、修改时间或切换时区后自动恢复未来提醒。
- 计划边界变化时自动刷新小组件。
- 本地离线存储，不收集或上传个人计划。

## 技术实现

- Kotlin
- Jetpack Compose + Material 3
- Android App Widget / RemoteViews
- AlarmManager 精确提醒
- BroadcastReceiver 负责通知、完成动作、开机恢复和小组件刷新
- SharedPreferences + JSON 本地持久化
- minSdk 26，targetSdk 35

## 构建

使用 Android Studio 打开项目根目录，等待 Gradle 同步完成后直接运行。

也可以在项目根目录执行：

```powershell
.\gradlew.bat assembleDebug
```

调试 APK 生成于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 提醒权限

Android 13 及以上需要通知权限。Android 12 及以上建议开启“闹钟和提醒”或“精确提醒”权限，否则系统可能延迟发送通知。应用首页会在权限未开启时给出引导。

部分手机厂商有独立的电池优化和后台限制。如果提醒仍然延迟，需要在系统设置中允许“有期”后台运行。

## 项目结构

```text
app/src/main/java/com/plannext/app/
├── alarm/    # 精确闹钟、通知、开机恢复
├── data/     # 计划模型与本地存储
├── ui/       # Compose 七日时间网格和计划编辑器
├── util/     # 日期与时间工具
└── widget/   # 桌面小组件及刷新逻辑
```

## 首版范围

当前版本聚焦于可靠的提醒与桌面可见性，暂未加入账号、云同步、重复计划、日历系统同步和社交功能。这些功能需要在后续版本中结合真实使用反馈再确定优先级。
